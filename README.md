# 🐣 우리 가족 기록장 — 태블릿 가로형

초코하임 · 호도리의 포근한 가족 기록장, 태블릿 가로 화면에 맞춰 새로 만든 버전입니다.
단일 파일 `index.html` 하나로 동작해요 (`file://`로 열거나 정적 호스팅에 올리면 됩니다).

## 구성원
- **초코하임** — 포근한 곰돌이
- **호도리** — 말랑한 토끼

## 메뉴 (6개)
| 메뉴 | 내용 |
| --- | --- |
| 홈 | 날씨·미세먼지(서울, Open-Meteo 실시간 + 예시 대체), 다음 일정·학원 준비, 오늘의 가족 미션, 오늘의 체크 요약, 구성원 카드 |
| 할 일 & 공부 | 매일 고정 루틴(아침 / 점심·귀가 후, 월요일엔 호도리 받아쓰기 자동), 터치로 바로 추가(11개 프리셋), 오늘만 하는 할 일, 공부 타이머(스톱워치·타이머, 저장 시 용돈·별 적립), 오늘의 공부 기록 |
| 도장판 & 칭찬 | 20칸 도장판(구성원별), 칭찬 스티커 보내기, 주고받은 칭찬 벽 |
| 용돈기입장 | 잔액 카드(시작 금액 수정), 공부 용돈 적립 규칙 · 30분 보너스 원탭 받기, 내역 추가/필터/삭제 |
| 가족 캘린더 | 월간 달력(일정 점 표시), 선택한 날 시간순 일정 + 학원 준비물, 매주 반복 일정, 이번 주 챙길 준비물 |
| 가족 건의함 | 건의 & 채팅, 빠른 문장, 스티커, 확인!/해줄게! 반응 |

## 매일 고정 루틴
- 아침(둘 다): 양치하기, 이불정리하기
- 점심·귀가 후(둘 다): 귀가 후 손 씻기, 영어 따라읽기 연습, 수학학습, 학교숙제
- 영어 집중듣기: 초코하임 1권 / 호도리 2권
- 월요일만(호도리): 받아쓰기 연습 — `월요일 고정` 배지
- 체크 상태는 날짜별로 저장돼 매일 새로 시작하고, 루틴은 추가·이름변경·삭제할 수 있어요.

## 저장
- `localStorage` 키: `family-record-tablet.v1`
- 사이드바 아래 **내보내기 / 불러오기**로 JSON 백업·복원

