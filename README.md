# 🐣 우리 가족 기록장

초코하임 · 호돌이 · 엄마, 세 사람의 하루를 한 곳에 담는 포근한 가족 기록 웹앱이에요.
**`index.html` 파일 하나만 있으면** 어디서든(휴대폰·PC·정적 호스팅) 바로 열립니다.

---

## 1. 바로 열어 보기

| 방법 | 설명 |
| --- | --- |
| 파일 열기 | `index.html`을 더블클릭 (Safari·Chrome 모두 OK) |
| 휴대폰에서 | 파일을 폰으로 보낸 뒤 브라우저로 열기 |
| 홈 화면 앱처럼 | iOS Safari → 공유 → **홈 화면에 추가** |
| 인터넷에 올리기 | 아래 배포 안내 참고 |

기록은 브라우저의 `localStorage`(키: `family-record-app.v1`)에만 저장되고, 서버로 아무것도 보내지 않아요.

## 2. 배포 (정적 사이트)

`family-record-app/index.html` 하나만 올리면 됩니다.

- **Netlify / Vercel / Cloudflare Pages**: 폴더를 끌어다 놓거나 Git 연결 후 빌드 명령 없이 배포 (output = 이 폴더)
- **GitHub Pages**: 저장소에 `index.html`을 올리고 Settings → Pages → Branch: `main` / root 선택

`file://`로 열든 `https://`로 열든 똑같이 동작하도록 CSS·JS·SVG를 모두 인라인으로 넣었어요.
(구글 폰트 `Jua`·`Noto Sans KR`만 온라인에서 불러오고, 없으면 시스템 한글 폰트로 자연스럽게 대체됩니다.)

## 3. 들어 있는 기능 (8개 탭)

1. **홈** — 날씨·미세먼지 카드(open-meteo, 도시 설정) / 가족 3명 카드(별·돼지저금통) / 도장판(월~일, 연속 일수, 달력 모달) / 오늘의 가족 미션(함께 N번)
2. **루틴** — 초코하임·호돌이·엄마 각자의 오늘 할 일(추가·수정·삭제·완료), 완료하면 도장 자동 적립
   - **오늘의 공부 플랜**: 진행률, 고정 항목 관리, 공부 추가(분량 태그·보상 금액), 공부 타이머(남은 시간/재는 시간, 10·20·30분 프리셋 + 직접 입력, 시작/일시정지/초기화), 아이별 체크리스트(📌·✏️·✕)와 체크 시 용돈 자동 적립
3. **식사** — 아침·점심·저녁·간식 기록, 메뉴 아이디어, 오늘 뭐 먹지 추천
4. **일정** — 월 달력 + 다가오는 일정(추가·삭제, D-day)
5. **건강** — 사람별 약 챙기기·물 마시기·컨디션·체온·메모
6. **칭찬** — 칭찬 보내면 별 +1 (홈 카드에 바로 반영)
7. **용돈** — 아이 전환 / 지금 모은 돈 / 시작 금액 수정 / 입금·사용 기록 / 매일 공부 적립 요약
8. **채팅** — 사용자 전환(+이 기기 잠금), 알림음 켜기/끄기, 말풍선·시간·❤️ 반응·삭제, 스티커 8종, 음성 메모 스타일, 빠른 문구

### 설정(⚙️)
- 우리집 도시(날씨·미세먼지)
- 알림음 / 이 기기 잠금
- 가족 이름·한 줄 소개·아바타(곰돌이·토끼·고양이)·목표 꾸미기
- JSON **내보내기 / 불러오기 / 기록 초기화**

## 4. 파일 구성

```
family-record-app/
├─ index.html            ← 완성된 앱 (이 파일만 있으면 됩니다)
├─ src/                  ← 수정용 소스
│  ├─ index.template.html
│  ├─ app.css
│  └─ js/00-core.js … 90-init.js
├─ build.py              ← src → index.html 로 묶기
├─ verify.py             ← 헤드리스 크롬으로 화면·동작 자동 점검
└─ screenshots/          ← 점검 스크린샷
```

고치고 싶을 때:

```bash
cd family-record-app
# src/ 파일을 수정한 뒤
python3 build.py        # index.html 다시 생성
python3 verify.py       # (선택) 화면·동작 자동 점검 + 스크린샷
```

`verify.py`는 Playwright(Chromium)가 필요합니다: `pip install playwright && python3 -m playwright install chromium`

## 5. 데이터와 동기화

- 모든 상태는 `localStorage`의 JSON 하나(`family-record-app.v1`)에 저장돼요.
- 데이터 계층은 `state` 객체 하나로 모여 있어서, 나중에 Supabase·Firebase를 붙일 때 `save()`/`load()`(src/js/00-core.js)만 서버 통신으로 바꾸면 됩니다.
- 기기 간 공유가 필요하면 지금은 **설정 → 내보내기**로 파일을 옮긴 뒤 **불러오기**로 넣으면 돼요.

## 6. 참고

- 날씨/미세먼지는 open-meteo API를 사용하며, 인터넷이 없으면 "날씨를 불러오지 못했어요 · 다시 시도" 카드가 표시됩니다.
- 미세먼지 등급 기준(환경부): 미세먼지 30/80/150, 초미세먼지 15/35/75 ㎍/㎥.
- 캐릭터·스티커·아이콘은 모두 직접 그린 인라인 SVG라 외부 이미지가 깨질 일이 없어요.
